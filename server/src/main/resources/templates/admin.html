Catalogue source

FMA rows are searchable metadata stored in this PostgreSQL catalogue. The FMA identifier is kept for provenance; it does not open a live song lookup. The import contains title, artist and release-year fields only, with no audio or cover art.

FMA metadata attribution is recorded in the project README.
